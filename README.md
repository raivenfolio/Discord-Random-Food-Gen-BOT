# Discord Bot Food Gen

This discord bot basically recommends you food store based on what food you want. It helps you find random food establishment based on specific food cuisine name in your city

it uses an API called OpenStreetMap Overapps API (OSM)

(It isnt a bit accurate sometimes but it does the thing ^^)
trying my hands on creating discord bots and get familiar.

## 🚀 How to Setup

1. **Clone the repo:**
   'git clone [your-github-link-sohuld-be-here]

2. Install some teeny wee bit txt dependency
- bash
  'pip install -r requirements.txt

3. Set up your Keys:
- create a file named 'key.env' in the folder along w the main.py
- add your discord token like this: DISCORD_TOKEN=your_inserted_token

4. Run the Bot:
   'python main.py'
   
## 🛠️ Commands
- you can do " !find [City] [food] "
  ex. !find Manila Ramen
